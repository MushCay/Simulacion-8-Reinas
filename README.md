# Problema de las 8 Reinas 

## Creador
<a href="https://github.com/MushCay"> @MushCay</a>

## Descripcion

Aplicación web interactiva con un tablero donde el usuario puede colocar las piezas en distintos ordenes hasta encontrar la solución. 
Proyecto perteneciente a la materia de simulación.

## Características

* **Simulación Interactiva**: Tablero grafico donde se pueden colocar las reinas hasta dar con la solucion.
* **Interfaz **: Desarrollada en HTML5 (`simulacion8Reinas.html`) con estilos en CSS (`styles8Reinas`).
* **Lógica en JavaScript**: Algoritmo de backtracking/búsqueda para colocar las piezas e interacciones del usuario (`js/`).
* **Recursos Visuales**: Iconos e imágenes del tablero y piezas (`img/`).

##  Estructura del Proyecto

```text
├── img/                       # Imágenes y recursos gráficos (fichas, tablero)
├── js/                        # Scripts 
├── styles8Reinas/             # Archivos CSS de estilos
└── simulacion8Reinas.html     # Interfaz de usuario y estructura HTML principal
